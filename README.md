# Personal Portfolio Website (เว็บไซต์รวบรวมผลงาน)

เว็บไซต์ Portfolio ส่วนตัวที่รวบรวมประวัติ ผลงานการพัฒนาเว็บแอปพลิเคชัน กิจกรรม และทักษะความสามารถทางด้านเทคโนโลยี ออกแบบด้วยสไตล์พรีเมียม มินิมอล และรองรับการแสดงผลทุกหน้าจอ (Responsive Web Design)

**Live Website:** https://badin04.github.io/my-portfolio

## Featured Projects (ผลงานเด่นในคลัง)

ภายในเว็บไซต์นี้จะเชื่อมโยงไปสู่ผลงานพัฒนาโปรเจกต์หลักๆ ได้แก่:

1. **Library Management System**
   * ระบบจัดการห้องสมุดในรูปแบบ Fullstack (Node.js + Express + SQLite) บนสถาปัตยกรรม MVC
   * **Source Code:** [คลิกดูโค้ดที่นี่](https://github.com/Badin04/library-App)
   * **Live Demo:** [คลิกเปิดหน้าเว็บ](https://library-app-yho4.onrender.com)

2. **Thai Fruit Ninja Learning Game**
   * เกม 2D บนมือถือ (Unity + C#) สำหรับฝึกทักษะและทบทวนพยัญชนะไทยสำหรับเด็กนักเรียน
   * **Source Code:** [คลิกดูโค้ดที่นี่](https://github.com/Badin04/Thai-FruitNinja-Learning)

## Tech Stack & Tools
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Framework / Styles:** Tailwind CSS (via CDN)
* **Design Philosophy:** Minimalist, Clean Code, Responsive Layout
* **Deployment:** GitHub Pages
* **🎨 UI Elements & Emojis:** พัฒนาและตกแต่งหน้าเว็บด้วย Emoji และสัญลักษณ์ต่างๆ โดยเรียกใช้ผ่านระบบ Clipboard History ของ Windows (คีย์ลัด `Windows` + `V`)

## 📂 Web Structure (โครงสร้างหน้าเว็บ)
```text
├── images/            # โฟลเดอร์เก็บรูปภาพและ Assets ทั้งหมด

├── contact.html       # หน้าข้อมูลการติดต่อ
└── style.css          # ไฟล์ปรับแต่งสไตล์เพิ่มเติม
